Aster brings together tools for reaching your computers, keeping files in step and building connected applications.

[Explore Aster](https://getaster.now/) · [SDK documentation](https://sdk.getaster.now/docs/) · [Open source and licences](https://getaster.now/open-source/)

### Access your computers and files

[**Portal Desktop**](https://getaster.now/products/portal-desktop/) lets you reach your own Mac or PC from a browser. [**Portal Files**](https://getaster.now/products/portal-files/) keeps working folders available across your machines, with on-demand data access for NFS and Kubernetes workloads.

### Build truly distributed applications

Connect machines securely, expose your data and keep application views in sync.

| Tool | What it helps you do |
| --- | --- |
| [Aster SDK & runtime](https://getaster.now/products/aster-sdk/) | Connect applications across networks with peer connectivity, dispatch and lifecycle handling. |
| [Aster Data](https://getaster.now/products/aster-data/) | Provide filtering, sorting and paging through OData without writing another query endpoint for each screen. |
| [Aster UI](https://getaster.now/products/aster-ui/) | Keep grids and forms in sync, show validation errors and preserve edits when a save fails. |

### Work with agents

[**Aster Exec**](https://getaster.now/open-source/aster-exec/) gives remote Linux jobs an identity so agents can retrieve output and cancel the right process. Public release links are being prepared.

[**AgentXchange**](https://getaster.now/open-source/agentxchange/) provides durable requests and replies between agents on different machines.

[**Web Security Proxy**](https://getaster.now/products/security-proxy/) assigns outbound web policies to people and agent sessions. Both are coming November 2026.
